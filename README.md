*******Registration Web App*******

This is a full-stack cloud project where users can register with their name, email, and phone number. The frontend is a static HTML form, and the backend is built with Node.js and MongoDB Atlas.



*******Features*******

- Form submission via REST API
- Frontend hosted-ready (S3 or local)
- MongoDB Atlas for cloud storage
- Basic error handling


*******Project Structure*******
registration-app/
├── frontend/ # HTML/CSS/JS
├── backend/ # Express API + MongoDB model
└── README.md





*******Tech Stack******

- HTML, CSS, JavaScript (Frontend)
- Node.js + Express (Backend)
- MongoDB Atlas (Database)
- AWS S3 (optional deployment)



*******Start Backend*******
cd backend
npm install
# create a .env file with your MongoDB URI
node server.js


*******Open Frontend********
Open frontend/index.html in your browser.
